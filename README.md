# Bass Fretboard Trainer — V1

V1 稳定版练习闭环：支持不限时/5秒/3秒练习。进入限时模式时只需点击一次“开始”，之后题目自动连续计时；需要中断时可以随时暂停，继续时以新题和完整时间恢复。

同一道题在答对前连续错两次才进入错题库。点击错题按钮后直接打开独立的“错题练习”对话框，不展示中间清单。
错题练习固定不限时且不显示暂停按钮。一次练习中只要弹错过，该题就继续保留；只有首次作答直接正确才从错题库移除。
错题未练完时可以随时退出，剩余错题会保留，并直接返回普通练习而不断开声卡。

普通练习使用保守的规则式智能强化：所有题目仍按轮完整覆盖；最近五次中出现至少两次错误/超时的项目，会在下一轮额外出现一次，额外题不超过本轮题量的 30%。连续三次首次作答正确后恢复普通频率。

网页包含“指板练习”和“乐理练习”两个主入口。乐理练习支持大调、自然小调、大调五声、小调五声和小调布鲁斯音阶，调内级数、两八度根音—五度音型，以及常用三和弦与七和弦琶音。音阶可指定根音弦；五度音型从 E 弦根音开始，和弦琶音可从 E/A 弦开始。第一个根音自动锁定实际八度，音名按调性正确使用升降号。
音阶类型、调与根音所在弦都可选择“不指定”或指定范围。每次重新开始会从当前有效范围选择题目，并尽量避免连续两次相同。
音阶、五度音型、和弦琶音和调内级数都可在练习区选择“显示音名”或“隐藏音名”，默认隐藏；切换显示状态不会更换当前题目。和弦琶音支持从 E 弦、A 弦或随机 E/A 弦起始，调内级数由系统随机出题。乐理练习暂不接入错题集。

所有练习均可跳过当前题目；跳过不会加入错题库。3 秒或 5 秒模式连续 5 题出现错误或超时后，会询问是否切换到不限时练习。
乐理练习将音阶、五度音型和和弦琶音列为核心练习，调内级数归入辅助记忆；练习类型保持直接可见，其余范围与提示选项收进训练范围设置。

每种练习会显示当前设置对应的题库覆盖状态。覆盖按不重复的有效题目计算，不等同于答对数；只有完整完成整道题后才算覆盖，中途弹错后纠正并完成仍会计入，只看题、跳过或未演奏超时均不计入。只要还有未覆盖题目，下一题会优先从未覆盖题中随机选择。不同题库设置在当前网页会话中分别保存覆盖集合，切换回来后继续补齐；全部覆盖后保持 `X / X ✓` 并恢复原有出题规则。计时和是否显示音名等不改变题库内容的选项不会创建新的覆盖记录，刷新或关闭网页后覆盖记录清空。

页面采用单页分层路径：首页先选择“指板练习”或“乐理练习”；乐理练习再进入音阶、五度音型、和弦琶音或调内级数。返回上一级时会停止当前音频检测，所有切换均在当前网页内完成。

音频设备在首页连接一次后，会在同一次网页使用期间保持连接。返回首页或乐理菜单时仅暂停题目判定，不关闭声卡；进入另一项练习后可直接演奏，用户仍可随时在全局音频栏中主动断开。

题目设置只在本次页面会话中保留：返回首页或切换练习后再进入，会恢复该练习刚才的选择；刷新或重新打开网页后恢复产品默认值。单独断开并重新连接音频不会清除设置。

电脑与 iPad 使用左右分栏：设置位于左侧并默认折叠，题目固定在右侧；手机宽度下自动改为纵向。桌面 1366×768、iPad 横屏 1024×768 与竖屏 768×1024 已完成一屏布局检查。

## 运行

在项目目录运行：

```bash
cd /path/to/bass-fretboard-trainer-v1
python3 -m http.server 8080
```

然后用浏览器打开 `http://localhost:8080/`。公网部署时请使用 HTTPS，以便浏览器允许麦克风访问。
