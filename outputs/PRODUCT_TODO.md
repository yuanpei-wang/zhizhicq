# Bass Fretboard Trainer — 产品待办

## 当前稳定版之后

- [ ] 真实演奏抗杂音优化：针对左手护弦、换把和碰弦产生的短促杂音，结合起音、持续时间和置信度过滤；以不漏掉轻弹音、不明显增加延迟为前提。
- [x] 错题库：同一道题第一次答错只提示重试；在未答对前连续第二次仍错，才加入错题库。
- [x] 错题练习：在错题练习中答对一次，从当前错题列表清除，但保留历史记录供后续间隔复习。
- [x] 学习数据：按“练习弦、目标音、是否区分八度”等条件记录尝试、错误、反应时间和连续正确次数。
- [x] 覆盖式随机：一轮内均匀覆盖题目，避免纯随机造成连续重复或长期遗漏。
- [x] 规则式智能强化：普通练习中适度增加常错项目；初版采用保守规则，不做复杂 AI 推荐。
- [ ] 真实用户数据优化：发布后根据完成率、错误率、反应时间和退出位置调整“常错”阈值与强化比例。
- [ ] 视频中的优化方向：说明错题库、间隔复习、智能强化会如何根据真实用户数据继续迭代。
- [x] 限时模式：不限时（默认）、5 秒、3 秒；超时与答错分开记录。
- [x] 性能原则：反应时间与学习记录按每次作答更新，不在音频逐帧分析中持续写入存储。
