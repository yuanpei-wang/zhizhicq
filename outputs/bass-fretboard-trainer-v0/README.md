# Bass Fretboard Trainer — V0

一个只用于技术验证的四弦贝斯实时音高检测页。它使用浏览器 Web Audio API 和 YIN 自相关算法，不上传或保存音频。

## 本机运行（Mac）

1. 将 Synido LIVE DOCK A20 连接 Mac，贝斯接入声卡。
2. 打开“终端”，进入本文件夹。
3. 运行 `python3 -m http.server 8080`。
4. 用 Chrome 或 Edge 打开 `http://localhost:8080`。
5. 点击“开始检测”，允许麦克风权限，再在设备列表选择 Synido LIVE DOCK A20。

不能直接双击 `index.html`：浏览器的麦克风权限通常要求 localhost 或 HTTPS。

## 推荐测试顺序

先弹四根空弦，每个音弹 5 次，每次让声音延续约 2 秒：

| 弦 | 预期音名 | 标准频率 |
|---|---:|---:|
| E 弦 | E1 | 41.20 Hz |
| A 弦 | A1 | 55.00 Hz |
| D 弦 | D2 | 73.42 Hz |
| G 弦 | G2 | 98.00 Hz |

然后测试同一根弦上的品位：E 弦 1 品 F1（43.65 Hz）、3 品 G1（49.00 Hz）、5 品 A1（55.00 Hz）、7 品 B1（61.74 Hz）、8 品 C2（65.41 Hz）、12 品 E2（82.41 Hz）；最后测试 G 弦 12 品 G3（196.00 Hz）和高把位音。

记录三件事：音名/八度是否正确、弹下到稳定显示的大致时间、延音期间是否跳到高八度。输入信号建议保持约 −35 至 −10 dB。
